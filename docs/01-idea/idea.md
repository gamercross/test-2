# 1단계 · 무엇을 만들지 정하기 — 국내 여행 추천 프로그램

- 받는 것: 만들고 싶은 것
- 하는 일: 어떤 불편을, 누구를 위해 풀지 정해요
- 남는 것: 한 문장으로 된 목표

## 재료

- 처음 말한 것: “1. 미션 소개 Python에서 API를 호출한다는 게 처음엔 막막하게 느껴집니다. 그런데 한 번 연결되는 순간, 가능성이 달라집니다.  LLM API가 추천을 하고, 지도 API가 위치를 찾고, 최종 리포트가 생성되는 흐름 — 이걸 손으로 조합합니다.  단일 API 호출이 아니라 여러 API를 엮어 인사이트를 만드는 과정, 그게 이번 미션입니다.  현대 서비스의 대부분은 API를 통해 데이터를 주고받습니다. AI 기능, 지도 데이터 등 다양한 서비스를 API로 손쉽게 연동할 수 있습니다.  이 미션에서는 LLM API와 지도 API를 조합하여 국내 여행 추천 프로그램을 개발합니다. 사용자가 여행 날짜를 입력하면, LLM이 해당 시기에 여행하기 좋은 지역을 추천하고, 지도 API로 맛집 정보를 검색한 뒤,”

## 불편

> 어떤 불편을 풀고 싶은지 한 문장으로 쓰기

- 여행 날짜에 어디가 좋은지, 맛집은 어디인지 하나하나 찾아봐야 해서 번거로워요.
- 어떻게: 플로로 초안을 그대로

## 달라지는 것

> 다 만들면 무엇이 달라지는지 쓰기

- 날짜만 넣으면 추천 지역과 맛집, 1일 일정이 담긴 여행 리포트가 만들어져요.
- 어떻게: 플로로 초안을 그대로

## 누가

> 누가 쓰는지 쓰기

- 여행 날짜를 입력해서 국내 여행 리포트를 받아 보는 사용자예요.
- 어떻게: 플로로 초안을 그대로

## 크기

> 얼마나 크게 만들지 정하기

- 크기: 보통 — AI와 지도 서비스를 불러 이어 쓰는 흔한 방법 하나로 풀려요.
- 어떻게: 고름 — 플로로가 권한 것: “보통 — AI와 지도 서비스를 불러 이어 쓰는 흔한 방법 하나로 풀려요.”
