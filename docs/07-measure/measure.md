## 숫자 재기

> 2단계에서 정한 숫자를 실제로 재 보기

- 아직 못 함 — 2단계 '언제 성공'의 숫자가 비어 있어요 — 그것부터 적어요
- 어떻게: 직접 적음(초안 없이)
- 재료: 3단계 Ⅱ 숫자로 · 2단계 Ⅱ 왜 · 어디까지 · 언제 성공

## 잰 값 적기

> 잰 값을 그대로 적어 두기

- 무엇: (재고 적기) · 잰 날: (재고 적기)
- 어떻게: 고름 — 플로로가 권한 것: “무엇: (재고 적기) · 잰 날: (재고 적기)”
- 재료: 3단계 Ⅱ 숫자로

## 못 잰 것

> 재지 못한 것을 '아직 못 함'으로 적어 두기

- 리포트 만드는 시간 · 맛집 개수 — 아직 못 함(정한 숫자가 아직 없어요)
- 어떻게: 고름 — 플로로가 권한 것: “리포트 만드는 시간 · 맛집 개수 — 아직 못 함(정한 숫자가 아직 없어요)”
- 재료: 3단계 Ⅱ 숫자로 · 6단계 Ⅳ 비밀값 검사

## 아무나 못 들어오게

> 공개한 앱에 아무나 들어오지 못하게 되어 있는지 확인하기

- 들어올 때 확인 — 불필요(4단계에서 사용자 본인이 자기 리포트만 보기로 했어요). 공개하기 전에 다시 볼래요.
- 어떻게: 고름 — 플로로가 권한 것: “들어올 때 확인 — 불필요(4단계에서 사용자 본인이 자기 리포트만 보기로 했어요). 공개하기 전에 다시 볼래요.”
- 재료: 4단계 Ⅴ 보는 사람 · 둘 곳 · 5단계 Ⅳ 비밀값 검사
