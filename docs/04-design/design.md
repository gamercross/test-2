## 후보 찾기

> 흔히 쓰는 방법 목록에서 먼저 후보를 2개 이상 찾기

- 서버가 있는 웹 / 화면 하나짜리 웹 / 표 계산 도구
- 어떻게: 고름 — 플로로가 권한 것: “서버가 있는 웹 / 화면 하나짜리 웹 / 표 계산 도구”
- 재료: 1단계 Ⅳ 크기 · 3단계 Ⅰ 기능 문장

## 견주기

> 후보끼리 좋은 점과 아쉬운 점 비교하기

- 서버가 있는 웹: 열쇠를 숨기고 AI·지도를 이어 쓰기 좋아요 · 화면까지 만들 게 늘어요 / 파이썬 프로그램: 날짜 넣고 리포트 받기까지 가장 빨라요 · 글자 창이라 보기엔 소박해요 / 휴대폰 앱: 여행 중에 꺼내 봐요 · 만들고 올리기 번거로워요
- 어떻게: 고름 — 플로로가 권한 것: “서버가 있는 웹: 열쇠를 숨기고 AI·지도를 이어 쓰기 좋아요 · 화면까지 만들 게 늘어요 / 파이썬 프로그램: 날짜 넣고 리포트 받기까지 가장 빨라요 · 글자 창이라 보기엔 소박해요 / 휴대폰 앱: 여행 중에 꺼내 봐요 · 만들고 올리기 번거로워요”
- 재료: 1단계 Ⅱ 달라지는 것 · 2단계 Ⅲ 한 문장 한 가지 · 3단계 Ⅰ 기능 문장

## 고른 까닭

> 고른 방법과 왜 골랐는지 한 줄을 기록으로 남기기

- 고른 방법: 서버가 있는 웹 — 까닭: 날짜만 넣으면 AI와 지도 서비스를 뒤에서 이어 부르고, 열쇠도 안전하게 숨길 수 있어서요
- 어떻게: 고름 — 플로로가 권한 것: “고른 방법: 서버가 있는 웹 — 까닭: 날짜만 넣으면 AI와 지도 서비스를 뒤에서 이어 부르고, 열쇠도 안전하게 숨길 수 있어서요”
- 재료: 1단계 Ⅳ 크기 · 3단계 Ⅲ 꼭 · 있으면 좋음

## 약속과 맞대기

> 지키기로 한 원칙(쓸 도구, 하면 안 되는 것, 화면 원칙)과 고른 방법 맞대어 보기

- 쓸 도구: 맞음 — AI와 지도 서비스를 이어 쓸 수 있어요 / 하면 안 되는 것: 맞음 — 날짜 말고 다른 개인 정보는 받지 않아요 / 화면 원칙: 아직 모름
- 어떻게: 고름 — 플로로가 권한 것: “쓸 도구: 맞음 — AI와 지도 서비스를 이어 쓸 수 있어요 / 하면 안 되는 것: 맞음 — 날짜 말고 다른 개인 정보는 받지 않아요 / 화면 원칙: 아직 모름”
- 재료: 2단계 Ⅳ 남의 정보 · 밖으로 · 3단계 Ⅴ 막을 일

## 보는 사람 · 둘 곳

> 누가 무엇을 볼 수 있는지, 정보를 어디에 둘지도 비교에 넣기

- 누가 무엇을 보나: 사용자 본인이 자기 리포트만 봐요 · 정보를 둘 곳: 서버(날짜와 추천 지역은 AI·지도 서비스로 나가요) · 들어올 때 확인: 불필요
- 어떻게: 고름 — 플로로가 권한 것: “누가 무엇을 보나: 사용자 본인이 자기 리포트만 봐요 · 정보를 둘 곳: 서버(날짜와 추천 지역은 AI·지도 서비스로 나가요) · 들어올 때 확인: 불필요”
- 재료: 1단계 Ⅲ 누가 · 2단계 Ⅳ 남의 정보 · 밖으로 · 3단계 Ⅴ 막을 일
